# Rackpad 1.8.4-beta.1 candidate

This beta branch candidate addresses rack-top placement, loose-device cables and
the guided hardware-template editor, and includes the custom-port healthcheck
repair and compatible maintenance. Studio remains opt-in. The classic rack view,
reference pictures and existing subtitle are retained. Native Proxmox LXC remains
experimental; Docker is the supported general deployment.

## Changes

- Rack Cabling shares the top-band geometry between rails, U labels, equipment
  and port anchors. Grouped topology represents rack-top devices without using
  rack U space; ordinary equipment retains its U positions.
- Loose equipment keeps its individual cable identities and paths through
  expansion/collapse. Collapsed cards show one destination summary per device
  with a cable count. Hover, keyboard focus and selection expose full endpoints.
  Expanded equipment uses physical anchors or labelled continuations for hidden
  faces and unavailable layouts. Focused details remain visible with Labels off.
- The guided editor has independent port-block Add/Update/Duplicate/Delete
  controls, stable edited IDs, unique new IDs, geometry controls and a correctly
  named Rows field. Module positions can be edited on either face. Referenced
  positions cannot be deleted until their modules are removed. Bays and artwork
  can be selected, duplicated, removed and repositioned independently.
- New translated guidance and [worked template examples](../HARDWARE_TEMPLATES.md)
  cover mixed RJ45/SFP blocks, module positions and a four-bay chassis. Built-ins
  remain editable through duplication; template saves do not rewrite device
  snapshots. Preview/apply retains linked-port protections.
- Image and all three Compose healthchecks resolve the container's `PORT` using
  the same parsing/fallback as the server. Existing user-defined overrides must
  be updated separately; host port mappings and probe timings are unchanged.
- Compatible patch/minor dependencies, scoped Chinese translations, localized
  Front/Rear labels and setup-node v7 are included. The current trusted-proxy
  parser and shipped security repairs are retained. Major upgrades, skins,
  per-member templates and community template sharing remain deferred.

## Getting the candidate

A successful push workflow publishes `ghcr.io/kobii-git/rackpad:beta`. Verify the
workflow for the exact beta commit has completed, pull that image, and record its
immutable digest and displayed application version before testing. The moving
tag may otherwise still point to the previous build.

This branch delivery does not itself create a version tag or GitHub Release.
Do not assume `ghcr.io/kobii-git/rackpad:1.8.4-beta.1` or versioned native
installation assets exist until a separately authorized tagged publication.
The stable `latest` channel is unchanged.

## Data and rollback

Schema remains **52**, with no migration or new public API/environment variable.
Retain a backup and the matching previous application/database/configuration/key
before updating. Template edits require preview/apply to change a device-owned
snapshot. Restore the matching previous state for rollback; never run an older
binary against a database schema it does not support. Rehearse recovery only on
disposable data.

349 server tests and 100 client tests; screenshot determinism and twelve Storage
compatibility cases passed. Both initial local architecture images passed hardened
runtime/API smoke, template and cable preservation, logical/native recovery and
scheduled Docker/Compose probes. arm64 ran natively; amd64 was emulated. The stock

vulnerability data. Full local reports retained unfixed Debian advisories; no Node

pass for the exact pushed commit before its beta image becomes available.
