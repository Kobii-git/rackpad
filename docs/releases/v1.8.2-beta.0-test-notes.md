# Rackpad v1.8.2-beta.0 release test notes

## Status

Release candidate preparation began on 2026-08-31. This document does not mark
the beta as published: the beta promotion PR, exact-commit workflow checks,
independent review, tag, multi-platform image, and post-publication smoke remain
required.

Rack Studio remains opt-in and the classic rack elevation remains the default.
Docker remains the recommended deployment. The experimental native Proxmox LXC
assets from `v1.8.1-beta.2` are retained without expanding their support status.

## Candidate changes

- Rack Studio room and focused-rack views use exact device-owned front/rear
  layouts for direct, shelf, rotated, side, and deterministically placed loose
  equipment.
- Hardware templates and explicit stable port bindings preserve canonical
  device, port, and cable identities while supporting exact physical layouts.
- Physical Visualizer nodes, Patch mode, routing, tracing, and SVG/PNG export use
  the same port geometry and face selection as Device settings and Rack Studio.
- Schema versions 46 through 48 add physical layouts, shared room/rack geometry,
  and cable inspection/waypoints without rewriting legacy inventory.
- Typed route authorization, pure layout reads/previews, dynamic room bounds,
  and reserved-template restore validation close the beta review findings.

## Compatibility and rollback

- Existing devices, ports, `portLinks`, racks, waypoints, and their IDs remain
  canonical. Automatic compatibility layouts add physical anchors without
  replacing those records.
- Migrations are forward-only. Rollback requires the untouched pre-upgrade
  database or volume snapshot together with the previous image. Never attach
  an older Rackpad image to a schema-48 database.
- Older logical backups without Rack Studio data remain accepted. Newer-schema
  backups remain rejected by older versions.

## Deferred and experimental boundaries

- Loose-device tray positions are deterministic rather than freely persisted.
- Breakout and fan-out ports remain deferred; one Rackpad port maps to one
  physical slot.
- Studio is not the default and the classic elevation is not removed.
- Real Proxmox VE Debian 13/Ubuntu 24.04 installation, update/rollback, and soak
  evidence remains incomplete. Passing `check:proxmox` is contract evidence,
  not proof of a successful real-host installation.
