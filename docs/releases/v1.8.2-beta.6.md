Experimental maintenance prerelease. Docker remains the supported general
deployment. Native Proxmox LXC remains experimental.

## Fixed

- Docker installer uses the channel/version-aligned canonical release manifest,
  forwarding supported runtime settings. Existing keys, environment values, and
  volume identity are preserved. Customized Compose files receive a proposal;
  recognized generated files receive a protected backup before replacement.
- Native LXC installation, activation, and rollback verification wait up to 60
  seconds for valid health, with bounded requests and prompt service-exit failure,
  before checking authentication status, the app shell, and collector endpoints.

  Release creation follows publication and uses reviewed release notes.
- Patch/minor dependency updates are grouped separately from major upgrades.
- Operator guides clarify current import behavior, permissions, proxy versions,
  encryption keys, discovery requirements, and historical planning documents.

## Upgrade precautions

This candidate retains beta.4/beta.5 security changes. Back up database/volume and
configuration together, keeping the original `RACKPAD_SECRET_KEY`. Schema 50
requires a key to encrypt inline SNMP communities. Missing-key migration fails
atomically. Losing the original key makes existing encrypted credentials unreadable.

Replace hop-count/truthy `TRUST_PROXY` with explicit controlled IPs/CIDRs. Restrict
access to the app port and overwrite forwarding headers at the public proxy.
OIDC sessions are revoked by schema 50 and roles are recalculated once at next
login. Configure a trusted administrator subject/group and verify local recovery;
email-based rules require boolean `email_verified: true`.

Traps default off. Re-enable only deliberately, with explicit UDP firewall rules,
and reconfigure historical trap-source credential links. Rotate SNMP communities
previously exposed through old APIs/backups on both Rackpad and affected devices.
Rollback requires the previous image and paired pre-upgrade database/configuration.
Do not attach an old image to a migrated database.
