## Fresh-install checklist

The following tests require disposable Proxmox VE 9.x `amd64` hosts and remain
unverified on both Debian 13 and Ubuntu 24.04:

- default resource installation and installation with a custom port;
- first administrator bootstrap;
- reboot persistence;
- systemd hardening and file ownership;
- backup creation, offline restore, and password reset;
- safe discovery mode;
- advanced discovery success or truthful refusal when the outer LXC blocks raw
  networking;
- UDP port 1162 closed by default;
- refusal when an existing Docker Compose deployment would collide.

Retain the disposable guests and record commands, observed results, and any
defects here. Phase 4 remains incomplete until both guest operating systems pass
and no unresolved data-loss, privilege, update, or release defect remains.
