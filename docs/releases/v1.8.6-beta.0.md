# Rackpad 1.8.6-beta.0

This beta adds consistent device hover/focus details and room/rack colors in the
navigation panel, updates the reviewed dependency targets and corrects accessible
names exposed by Axe 4.14. It includes main's 1.8.5 changes and the original
maintainer screenshot-stability commit from #197. Docker remains the supported
general deployment; native Proxmox LXC remains experimental.

## Changes to test

- **#198:** hover and keyboard-focus devices in classic racks, Studio, grouped and
  pyramid Visualizer, both Diagram presentations and Rack Cabling. Available
  fields are name, distinct hostname, manufacturer/model, management IP and MAC.
  Check tiny/long labels, zoom, rotation, shelves, loose devices and stacks.
  Escape dismisses details; port selection, dragging and navigation remain usable.
- **#195:** save white, black or saturated room/rack header colors. The navigation
  panel colors the complete name-and-count row with contrasting text; descriptions
  and capacity bars retain their theme background. Check active/inactive rows,
  keyboard focus, both themes, RTL, reset and reload.
- **#191:** verify sidebar version/lab/search, monitoring layout controls and stack
  movement names. The accessibility rule and severity thresholds remain enabled.
  MCP transport/proposals and SMTP delivery/rejection have automated regressions.
- **#197:** stack-member screenshots retain exact image equality after controls,
  fonts and animation frames settle. **#192:** CodeQL retains raw failure evidence
  and reviewed summaries with the updated artifact uploader.

See the [Visualizer guide](../VISUALIZER.md) for the saved presentation settings.
The 28-case Chromium/Firefox acceptance selection explicitly covers the new UI
scenarios as well as editor, custom-type, round-template, mixed-stack and MCP
workflows. Automated results do not replace acceptance on a reporter's inventory,
client, Cisco hardware, Ubuntu custom-user configuration or native LXC guests.
Template sharing, skins and direct-rack rotation remain later roadmap work.

## Obtaining the beta

This source version does not assert that an image has been published. A push to
`beta` starts the existing quality, CodeQL, Trivy, image-build and smoke workflow.
Wait for that exact revision's workflow to complete successfully before using
`ghcr.io/kobii-git/rackpad:beta`; record the resulting immutable digest and displayed
version. A branch push alone does not create a GitHub Release or an immutable
`1.8.6-beta.0` image tag. Stable remains 1.8.5.

## Upgrade and rollback

Schema is **55**, unchanged from 1.8.5. Older beta installations may advance to
55 when bringing in the existing main migrations. Before updating, retain a
consistent database/configuration/key snapshot and its matching previous image.
Rehearse on disposable data. A rollback restores that pair; never attach older
binaries to a database whose schema they do not support.

No new API, environment variable, persistent preference, network exposure or
license change is introduced by this beta's backlog fixes. Node 22 remains the
runtime requirement. Use Node 22.12 or newer within Node 22 for development.
Hosted Linux storage, Net-SNMP, scanner and architecture smoke gates remain
required; local Docker Desktop results cannot establish Linux ownership behavior.
