# Rackpad 1.8.4-beta.8

This beta combines the placement and Visualizer fixes, opt-in MCP inventory
proposals, and vetted dependency maintenance. The `beta` branch image is published
only after quality, CodeQL, security, and container build checks pass. No tag or
GitHub Release is created by the branch push.

## Upgrade and rollback

Schema **53** adds hashed MCP token storage. Before upgrade, record a protected
snapshot of the existing database and pair it with the prior image. Migration is
forward-only: an older image must use that pre-upgrade snapshot, never the
schema-53 database. Logical and native backups omit MCP tokens, so restore
revokes them. In-memory proposals expire after one hour or on process restart.
No existing inventory is moved or merged by the upgrade.

Run smoke tests on the published `beta` image after CI succeeds. Leave the
linked issues open until testers confirm the behavior.
